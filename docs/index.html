AsterOS is a 32-bit x86 operating system. This page boots the same ISO used by the project inside the v86 PC emulator.

Click the emulator to focus the keyboard. AsterOS uses the existing VGA text-mode interface, so everything runs directly in the emulated PC.

About this demo

The browser build downloads pinned v86 assets during the Pages deployment and builds a fresh AsterOS ISO from this repository. v86 is an x86 emulator/JIT designed to run in the browser.
