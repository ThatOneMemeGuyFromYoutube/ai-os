ASTEROS

Run AsterOS in your browser

AsterOS is a 32-bit x86 operating system. This page boots the same ISO used by the project inside the v86 PC emulator.

Preparing emulator…

SeaBIOS is the default system firmware. Choose experimental AsterBIOS before Reset to try the separately built AsterOS-branded SeaBIOS derivative; use SeaBIOS if it fails. The VGA BIOS is unchanged. Choose NE2K or VirtIO before Reset to control which virtual NIC v86 presents to AsterOS. AsterOS includes a polling RTL8029/NE2K driver, a static local IPv4 address, ARP replies, and ICMP echo replies for a directly connected peer; VirtIO support is not implemented yet. The browser demo still has no configured v86 network backend, so it does not provide host or Internet connectivity. Click the emulator to focus the keyboard and capture the mouse. Press Esc to release the pointer.

About this demo

The browser build downloads v86's generated browser runtime and default BIOS assets, builds the optional AsterBIOS ROM and corresponding source archive, and builds a fresh AsterOS ISO from this repository. v86 provides an x86 PC environment directly in the browser.
