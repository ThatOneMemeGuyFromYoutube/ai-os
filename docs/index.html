AsterOS is a 32-bit x86 operating system. This page boots the same ISO used by the project inside the v86 PC emulator.

Click the emulator to focus the keyboard and capture the mouse. Press Esc to release the pointer. The Fullscreen button uses v86's built-in browser fullscreen support.

About this demo

The browser build downloads v86's generated browser runtime and BIOS assets during the Pages deployment and builds a fresh AsterOS ISO from this repository. v86 provides an x86 PC environment directly in the browser.
