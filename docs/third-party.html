Third-party notices

The browser demo uses v86, an x86 emulator/JIT for the browser.

v86 is distributed under the Simplified BSD License and includes third-party components with their own licenses. The demo downloads the v86 browser assets during its GitHub Pages build rather than adding generated binaries to the AsterOS source tree.

The default browser firmware remains the SeaBIOS and VGA BIOS images distributed with v86. The optional AsterBIOS selection is a separate SeaBIOS 1.17.0 build with an AsterOS version suffix; it does not replace the default. SeaBIOS is available under LGPLv3 (and upstream files may carry GPLv3 terms). The Pages build publishes the exact corresponding SeaBIOS source archive, GPL license text, and LGPL license text beside the experimental ROM. The VGA BIOS remains v86's upstream image.
